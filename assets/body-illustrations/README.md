# Training body illustrations

Four generated transparent PNG assets (1024 × 1536), created for GRITTT from the user's approved visual reference on 2026-11-20. Adult male/female front and back views use grey sculptural anatomy and charcoal training clothes. These are illustrative avatars, not scans or measurements of a user's body.

`BodyIllustration.tsx` displays these pictures and overlays lime regions from the last seven days' logged strength sets. The paths are artwork-specific visual approximations of the app's seven muscle categories. No highlight appears for zero sets. The default body preference displays the male illustration; users can explicitly choose male or female from the card's body selector. The female chest region is shown through clothing as an illustrative training region.

Generation brief: full-body straight-on orthographic front/back views, symmetric relaxed pose, grey clay muscle definition, sculpted hair, charcoal fitted shorts (plus sports bra for female), bare feet, transparent background, no text/UI or baked-in colored highlights. Back views were generated using the corresponding front image as the identity/pose reference. Assets are bundled locally; displaying or switching them makes no AI/network call.

The Physical card uses static Front/Back buttons. Filament is not mounted by this card. Existing model assets are retained for legacy consumers and the separate Food diagram.
